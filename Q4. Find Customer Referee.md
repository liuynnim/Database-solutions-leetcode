# Intuition
We need to list the names of customers whose referee is **not equal to 2** or who do not have a referee at all. The problem is straightforward: filter out customers with `referee_id = 2`, while keeping all others.

# Approach
- Use a simple `WHERE` clause to exclude rows where `referee_id = 2`.  
- Include customers with no referee by checking `referee_id IS NULL`.  
- Combine the two conditions with `OR`.  
- Select only the `name` column as required by the problem.

# Complexity
- **Time complexity:**  
  \(O(n)\), where \(n\) is the number of rows in the `Customer` table. Each row is checked once against the condition.

- **Space complexity:**  
  \(O(1)\), since no extra data structures are required beyond the result set. The database engine handles filtering internally.

# Code
```mysql
SELECT name 
FROM Customer
WHERE referee_id != 2
   OR referee_id IS NULL;
