# Intuition
We need employees who earn less than 30000 and whose manager has left the company.  
Instead of joining the entire table, we first filter the employees that meet the salary condition and have a non-null manager. This reduces the dataset before performing the join.

# Approach
- Step 1: Filter employees with `salary < 30000` and `manager_id IS NOT NULL`.  
- Step 2: Use `LEFT JOIN` with the `Employees` table to check if the manager exists.  
- Step 3: If the manager has left, the join will result in `m.employee_id IS NULL`.  
- Step 4: Return the `employee_id` ordered by ascending value.

# Complexity
- **Time complexity:**  
  \(O(k)\), where \(k\) is the number of employees with salary < 30000 and non-null manager. This is smaller than \(n\), the total number of employees, so the join is more efficient.

- **Space complexity:**  
  \(O(1)\), since no extra structures are needed beyond the result set.

# Code
```mysql
SELECT e.employee_id
FROM (
    SELECT *
    FROM Employees
    WHERE salary < 30000
      AND manager_id IS NOT NULL
) e
LEFT JOIN Employees m
  ON e.manager_id = m.employee_id
WHERE m.employee_id IS NULL
ORDER BY e.employee_id;
