# Intuition
We need to find employees who earn less than 30000 and whose manager has left the company.  
When a manager leaves, their record is deleted from the `Employees` table, but the employees still keep the `manager_id`.  
So, the task is to detect employees with `salary < 30000` and whose `manager_id` does not match any existing `employee_id`.

# Approach
- First, filter employees with `salary < 30000` and `manager_id IS NOT NULL`.  
- Use a `LEFT JOIN` to join the filtered employees (`e`) with the `Employees` table (`m`) on `e.manager_id = m.employee_id`.  
- If the manager has left, the join will result in `m.employee_id IS NULL`.  
- Select the `employee_id` of those employees.  
- Order the result by `employee_id`.

# Complexity
- **Time complexity:**  
  \(O(n)\), where \(n\) is the number of rows in the `Employees` table. With proper indexing on `employee_id` and `manager_id`, each lookup is efficient.

- **Space complexity:**  
  \(O(1)\), since no extra data structures are required beyond the result set. The database engine handles intermediate operations internally.

# Code
```mysql
SELECT e.employee_id
FROM (
    SELECT *
    FROM Employees
    WHERE salary < 30000
      AND manager_id IS NOT NULL
) e
LEFT JOIN Employees m
  ON e.manager_id = m.employee_id
WHERE m.employee_id IS NULL
ORDER BY e.employee_id;
